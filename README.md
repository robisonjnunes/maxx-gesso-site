# Maxx Gesso Distribuidora — site

Site institucional da Maxx Gesso Distribuidora (Tatuí/SP). Página única em HTML/CSS/JS puro, sem build.

## Estrutura
- `index.html` — página completa (estilos e scripts embutidos)
- `img/` — logo, favicon e fotos dos produtos

## Como editar
- **WhatsApp:** altere `var WHATSAPP = '5515991858433'` no final do `index.html` (e o número exibido na página).
- **Endereço/horários:** seções "Como chegar", rodapé e o bloco `application/ld+json` no topo.

## Ver localmente
Abra o `index.html` no navegador, ou rode `python -m http.server` nesta pasta.
